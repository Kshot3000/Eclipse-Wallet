Security

Your keys, your coins

Eclipse is self-custody by design. Nothing is phished to a server, and nothing is signed without you.

🔒

Encrypted vault

Seed encrypted with AES-256-GCM, keyed from scrypt (N = 2¹⁴, r = 8, p = 1) over your password. Wrong password → no seed.

🧊

Memory-only seed

After unlock the seed lives only in the popup's page memory. Locking discards it; it is never written to disk again.

🛰️

Keyless background

The service worker only brokers dApp requests and notifications. It never sees your keys or touches a signature.

✅

Per-request approval

Every dApp request needs an explicit approve or reject — with a badge, a desktop notification, and optional origin memory.

🎯

Minimal permissions

Only storage + notifications, with network access restricted to the three public APIs the wallet actually uses.

🗝️

Your recovery phrase

A 24-word BIP39 phrase is your only backup. Shown once, never stored, and no one else can recover it for you.

dApps

Built for the dApp economy

A small, honest provider API — approve what you want, sign when you choose.

// Eclipse injects window.eclipse on every http(s) page const addr = await window.eclipse.getAddress('cardano'); // Or ask for a message signature (you approve first): const sig = await window.eclipse.signMessage( 'bitcoin', 'Hello from my dApp!' ); // → { chain, scheme, signature, pubKey, address }

Nothing silent, ever

Requests queue in the wallet with a badge and a desktop notification. Approve, reject, or remember a trusted origin.

Native signing per chain

ed25519 on Cardano, bip340-schnorr on Midnight, ecdsa-secp256k1-sha256 on Bitcoin — each checked against official spec vectors.

No key access in the broker

Signing happens in the unlocked popup. The worker that relays dApp traffic cannot derive or sign anything.

Install

Live in under a minute

No store, no install size — Eclipse is an unpacked extension that loads in three clicks on Chrome or Brave.

1

Open the extensions page

chrome://extensions in Chrome, or brave://extensions in Brave.

2

Load the extension

Flip on Developer mode, click Load unpacked and pick the extension/ folder from the repository.

3

Create your wallet

Pin Eclipse, create (or import) a wallet, write down your 24 words — then start sending across three chains.
